## Brand greens — presentation palette

| Name | Hex | Use |
|------|-----|-----|
| Dark Teal | `#1E3A34` | Section divider backgrounds, cover color blocks |
| Forest Green | `#4A7C59` | Secondary blocks, charts, highlights |
| Sage Green | `#7A9E6E` | Horizontal divider bars, subtle accents |
| CTA / Accent | `#FF5723` | Single most important text or element per slide |
| CTA Hover | `#CE3708` | Interactive states only |
| Text Link | `#10A1AF` | Hyperlinks |

### 60-30-10 rule
When using all three greens on one slide: Dark Teal ~60% of colored area, Forest Green ~30%, Sage Green ~10%.

## Grayscale system

| Token | Hex | Typical use |
|-------|-----|-------------|
| Black 100 | `#000000` | Rarely used |
| Black 90 | `#1A1A1A` | Slide titles, primary text |
| Black 80 | `#2E2E2E` | Body text |
| Black 70 | `#454545` | Secondary body |
| Black 60 | `#757575` | Page numbers, captions, muted text |
| Black 50 | `#959595` | Placeholder, disabled |
| Black 30 | `#DFDFDF` | Divider lines, light borders |
| Black 20 | `#ECECEC` | Card backgrounds |
| Black 10 | `#F5F5F5` | Page background (light slides) |
| White | `#FFFFFF` | Standard slide background, text on dark bg |

| Use | Hex |
|-----|-----|

| Error | `#ED0000` |
| Note / annotation | `#FF0099` |

## Usage rules

- **Per slide**: maximum 3 colors (excluding white and black/gray scale)
- **Accent `#FF5723`**: maximum 1–2 appearances per slide; reserved for the single highest-priority element
- **Dark backgrounds** (`#1E3A34`): section dividers only, never on regular content slides
- **Text on dark bg**: always `#FFFFFF`
- **Text on light bg**: `#1A1A1A` (primary) or `#757575` (secondary)
